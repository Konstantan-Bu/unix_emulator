# UNIX Command Line Emulator

Эмулятор командной строки UNIX-подобной операционной системы, разработанный в рамках лабораторного практикума по конфигурационному управлению.

## Этап 1: REPL (Интерактивный режим)
На данном этапе реализован минимальный прототип консольного приложения:
- Интерактивный интерфейс (CLI) с динамическим приглашением вида `username@hostname:~$`[cite: 128].
- Парсер командной строки с поддержкой раскрытия переменных окружения реальной ОС (например, `$HOME`)[cite: 128].
- Команды-заглушки `ls` и `cd`, выводящие свое имя и переданные аргументы[cite: 128].
- Штатное завершение работы с помощью команды `exit`[cite: 128].
- Обработка ошибок ввода и синтаксиса[cite: 128].
